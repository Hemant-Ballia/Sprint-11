# Cine-Stream

Full-stack movie and post application built with Next.js, Express, MongoDB and Cloudinary.

## Tech Stack

- Next.js
- React
- Express.js
- MongoDB
- Mongoose
- Cloudinary
- Multer

## Features

- Browse popular movies
- Create posts
- Image upload with Cloudinary
- Delete posts
- MongoDB persistence
- Responsive UI

## Project Structure

```text
backend/      Express API
cine-stream/  Next.js frontend
```
